## 📌 Overview

The **Online Courses Analysis Dashboard** is an end-to-end
**Power BI data analytics project** built to explore and
visualize trends in the global online education industry.

With the rapid explosion of e-learning platforms like **Udemy,
Coursera and edX**, this dashboard answers critical questions:

> 🤔 *Which courses are most popular?*
> 🤔 *What skills are employers looking for?*
> 🤔 *Which languages dominate online learning?*
> 🤔 *How do instructor ratings vary across subjects?*

This project covers the **complete data analytics workflow** —
from raw data to interactive dashboard to business insights.

📂 Raw Data (Excel)
↓
🧹 Data Cleaning (Power Query)
↓
🔄 Data Transformation (DAX)
↓
📊 Dashboard Design (Power BI)
↓
💡 Insights & Storytelling



---

## 🧹 Data Preparation

| Step | Action | Tool |
|------|--------|------|
| 1 | Removed null & duplicate values | Power Query |
| 2 | Standardized category & language columns | Power Query |
| 3 | Fixed incorrect data types | Power Query |
| 4 | Created calculated columns | DAX |
| 5 | Built ranking measures (Rank, Rank2) | DAX |
| 6 | Aggregated viewer count by sub-category | DAX |

---

## 📊 Dashboard Features

| Visual | Type | Purpose |
|--------|------|---------|
| Course Type Popularity | Bar Chart | Compare course counts by category |
| Avg Viewers by Sub-Category | Bar Chart | Identify high-engagement topics |
| Demanding Skills | Word Cloud | Visualize most in-demand skills |
| Courses by Language | Pie Chart | Language distribution breakdown |
| Instructor Rating by Value | Bar Chart | Compare instructor performance |
| Viewers per Subtitle | Line + Bar | Track viewer trends by subtitle count |
| Top Ranked Table | Table | Rank2 score leaderboard |
| Category Filter | Slicer | Interactive drill-down by category |

## 🚀 How to Run This Project

```bash
# Step 1 — Download the repository
Click "Code" → "Download ZIP" or clone via Git

# Step 2 — Open Power BI Desktop
Make sure Microsoft Power BI Desktop is installed

# Step 3 — Open the dashboard file
File → Open → Select powerpip2.pbix

# Step 4 — Explore the dashboard
Use slicers and filters to interact with the visuals
```
