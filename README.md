## 📌 Project Overview
An interactive Power BI dashboard analyzing online course trends,
viewer counts, instructor ratings and top-performing categories.

---

## 🔍 Key Insights
- 🏆 **Data Science** is the #1 most popular category
- 🌍 Top languages: **English, Japanese, Spanish**
- ⭐ Instructor ratings vary across sub-categories
- 👥 Viewer count trends by sub-category
- 💡 Word cloud of most **in-demand skills**
- 📊 Top ranked courses by viewer count
