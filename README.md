#### 📌 Project Description

The **Online Courses Analysis Dashboard** is a comprehensive
Power BI project built to analyze and visualize trends in the
online education industry. With the rapid growth of e-learning
platforms, this dashboard helps understand **which courses are
most popular, what skills are in demand, how instructors are
rated**, and which languages dominate the online learning space.

This project involved:
- 🧹 **Data Cleaning** — Removing nulls, fixing data types,
  standardizing categories in Excel & Power Query
- 🔄 **Data Transformation** — Creating calculated columns
  and measures using DAX
- 📊 **Dashboard Design** — Building an interactive,
  filterable Power BI report with multiple visual types
- 💡 **Insight Generation** — Drawing meaningful conclusions
  from viewer trends, ratings and course rankings

#### 🔍 Key Insights

| # | Insight | Detail |
|---|---------|--------|
| 🏆 | Top Category | **Data Science** leads all categories |
| 🌍 | Top Languages | English → Japanese → Spanish |
| 👥 | Viewer Trends | Highest views in Tech sub-categories |
| ⭐ | Instructor Ratings | Strong variation across subjects |
| 💡 | Top Skills | Data Analysis, Visualization, Python |
| 📊 | Course Ranking | Ranked by Rank2 engagement score |
